# 残業時間管理アプリ 17+

1台のスマホの中に記録を保存する残業管理アプリです。ログインやSupabaseは不要で、オフラインでも使えます。

## iPhoneで使う

既存の17+をホーム画面から開いて使います。新しく追加する場合はSafariで公開URLを開き、共有メニューの「ホーム画面に追加」を選びます。既存のアイコンを削除する必要はありません。

17+の「退勤打刻」を押して記録し、同じアプリの中で集計・修正・休日出勤・深夜退勤・早出打刻・バックアップと復元を行います。

iPhoneではSafariとホーム画面アプリの保存領域が分かれます。別々の「退勤」と「17+」を端末保存だけで同期する前提にせず、毎回同じホーム画面アプリから打刻・集計・復元してください。1回タップで打刻する「退勤」を使う場合も、打刻後の「記録を見る」から同じアプリ内で集計・復元できます。

以前のクラウド記録は、iPhoneの「ファイル」に置いた `17plus-backup.json` を17+の「復元」で選んで取り込みます。現在の記録と統合し、同じ勤務日は更新時刻が新しい記録を優先します。個人の記録は公開サイトやGitへ含めません。

更新は既存と同じGitHub PagesのURLへ反映します。今のホーム画面アイコンをオンラインで開き直し、「端末保存」と表示されることを確認してください。

## バックアップと復元

17+の「バックアップ」を押し、iPhoneの共有メニューで「ファイルに保存」を選びます。ファイル共有に対応していないブラウザではJSONをダウンロードします。機種変更・アプリの削除・データ消去の前に、端末の外にもコピーしてください。新しい端末では「復元」からそのファイルを選びます。

復元前にファイル全体を検証します。不正な記録や重複した勤務日があれば取り込みを中止し、現在の記録を保持します。通常の復元では、ファイルにない現在の記録も保持します。復元する範囲は直近12期間です。

記録と早出の仮打刻をまとめて保存します。保存できなかった場合は成功扱いにせず、以前の記録を保持します。対応ブラウザでは永続保存を要求しますが、アプリ削除や端末故障には上記のファイルが必要です。

## 集計ルール

- 集計期間は16日から翌月15日までです。
- 残業は17:00以降を1分単位で計算し、秒は切り捨てます。
- 17:00〜17:15、19:15〜19:30、21:30〜21:45は休憩として除外します。
- 平均は打刻した日数で計算します。未打刻日は休日として扱います。
- 直近12期間を保持し、現在期間と前期間を修正できます。
- 17時前の退勤は通常0分です。
- 深夜帯は「残業ですか？」の確認で、はいなら前日分の残業、いいえなら0分として記録します。
- 早出は17+の「特殊な勤務」から「早出」を選び、8:35より前に「出勤打刻」を押します。退勤時に早出分を加算します。
- 休日出勤は「特殊な勤務」から選びます。8:35開始で、10:00〜10:10、11:45〜12:30、15:00〜15:10と夕方の3休憩を除外します。
- 土日祝も記録した日は集計対象です。

## ブラウザ版と検証

`index.html` を開いて使えます。そのブラウザ・ホーム画面アプリのローカルストレージに保存します。以前の端末記録は最初の保存時に移行し、古い保存キーを保持します。新形式で削除した記録は、旧復旧用データから再追加しません。Service Workerでアプリを保存し、初回の読み込み後はオフラインでも使えます。他の案件のキャッシュは削除しません。

`android-clockout/` は以前のAndroid用の補助アプリです。今回のiPhoneでの利用には使いません。

```powershell
node --test tests/*.test.js
```
