# 残業時間管理アプリ

スマホでの利用を想定した、ブラウザだけで動く残業時間管理アプリです。
残業した日に退勤時刻を記録する前提で作っています。

## 使い方

1. `index.html` をブラウザで開きます。
2. 退勤時に「退勤打刻」を押します。
3. 同じ勤務日に再度保存する場合は、確認後に上書きします。
4. 残業なしの日も打刻すると、平均の計算対象になります。
5. 直近1年の月別推移と、この期間の記録を棒グラフで確認できます。
6. Supabaseへログインすると、端末保存の記録をクラウドにも同期します。

iPhoneのホーム画面アプリでは、メール内のログインリンクを直接開くと別のブラウザへログイン情報が保存されることがあります。最初にメールリンクで開いたブラウザの「設定」からパスワードを設定し、その後ホーム画面アプリでメールアドレスとパスワードを入力すると、端末保存の記録を保ったままログインして同期できます。メールリンクを長押ししてコピーし、ホーム画面アプリへ戻ってログインする方法も残しています。

## スマホで開く

会社で使うには、GitHub PagesやNetlifyなどで公開URLにしてからスマホで開きます。
未ログイン中はこの端末に保存し、Supabaseへログインするとクラウドにも同期します。

公開後はスマホのブラウザでURLを開き、ホーム画面に追加して使います。

### 「退勤」アイコンから1タップで打刻

Android用の補助アプリをインストールすると、既存の「17+」とは別に「退勤」アイコンが追加されます。
初回だけSupabaseへログインした後は、「退勤」アイコンを押した時刻をそのままSupabaseへ保存します。
通常の「17+」は集計確認、手入力、修正、休日出勤、深夜退勤に引き続き使います。

- 打刻処理中も管理画面やブラウザは開きません。
- 保存結果は画面下部の短いメッセージと振動で知らせます。
- 同じ勤務日の記録が既にある場合は上書きしません。
- 平日の通常勤務と早出打刻に対応します。土日と5:00より前の退勤は誤計算を避けるため「17+」から打刻します。

Android補助アプリの構成とビルド方法は [`android-clockout/README.md`](android-clockout/README.md) にあります。

## 集計ルール

- 集計期間は16日から翌月15日までです。
- 残業は17:00以降です。
- 17:00から17:15、19:15から19:30、21:30から21:45は休憩として除外します。
- 残業は1分単位で、秒は切り捨てます。
- 平均は打刻した日数で計算します。未打刻日は休日として扱います。
- 保存・表示する記録は直近1年分です。それより古い記録は削除します。
- 現在期間と前期間は修正できます。2カ月前になった期間は確定済みとして、一覧や修正・削除を表示しません。
- 17時前の退勤は、通常は残業0分として扱います。
- 深夜帯は「残業ですか？」の確認で、はいなら前日分の残業、いいえなら0分として記録します。
- 休日出勤は「特殊な勤務」から選んで記録します。
- 早出は出勤時に「特殊な勤務」から「早出」を選び、「出勤打刻」を押します。退勤時に早出分を自動で加算します。
- ログイン中の早出出勤打刻は、退勤前の仮情報としてクラウドにも退避します。
- 休日出勤は8:35開始、10:00〜10:10、11:45〜12:30、15:00〜15:10、17:00〜17:15、19:15〜19:30、21:30〜21:45を休憩として計算します。
- 土日祝も、記録を付けた日は集計対象です。

## 保存先

未ログイン中の記録はブラウザのローカルストレージに保存します。ログイン前には端末記録の復旧用スナップショットを別キーへ残し、クラウド記録と更新時刻で統合してから同期します。
